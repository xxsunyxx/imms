## 二、这到底是个什么游戏

剧本杀 = 角色扮演 + 推理 + 社交（S4），源头是「谋杀之谜」。一场完整游戏需要六个要素（S5）：明确前提（有人死了）、角色分配、每人有别人不知道的秘密信息、专门的调查轮、指控/投票、主持人揭晓答案。

玩家侧的基本约定（S1/S3/S5）：

- 拿到角色本后记住三件事：**自己是谁、案发时段在哪里做什么（时间线）、和谁有什么关系/秘密**。
- 自我介绍用**第一人称**讲明面信息，不照本念，不爆核心任务。
- 调查的本质是对话：提问、对比陈述、找时间线矛盾；线索可分批发，拿到后可公开、部分公开或隐藏。
- 凶手不自曝、稳住立场、把嫌疑引向别人；非凶手围绕线索积极分享。
- 不许「贴脸」（用场外话发誓）、不许「跳车」（中途退出）、鼓励代入但不强迫专业表演。

常见分类（S4）：本格/变格；硬核推理、情感、欢乐、恐怖、机制、还原本；盒装/城限/独家；常见 4–9 人，人数固定不可中途加人。

## 三、标准流程（主持人视角）

| 阶段 | 玩家做什么 | DM 职责 | 关键规则 |
|---|---|---|---|
| 1. 开场与发本 | 选/领角色，读本到指定页，做笔记 | 说明背景与规则，做破冰引导，讲禁令 | 不剧透；提示别照本念、别贴脸、别跳车（S1/S2） |
| 2. 自我介绍 | 第一人称介绍姓名、职业、目的、明面关系 | 引导顺序，必要时给模板 | 不爆任务、不念本；用角色姓名互称（S1/S2） |
| 3. 搜证 | 用行动点搜地点/人物，拿到线索卡 | 按规则发线索、说明公开/隐藏规则 | 通常不能搜自己；线索可隐藏但有限制（S3/S1） |
| 4. 公聊/讨论 | 分享线索、对时间线、质疑与辩护 | 跟进但不参与对话，控制秩序 | 不评判、不带情绪、不打断玩家节奏（S2） |
| 5. 分幕推进 | 读到「未经允许不许翻页」就停 | 给信号推进下一幕、按阶段发线索 | 信息交流差不多或任务完成时推进（S1/S7） |
| 6. 投票指控 | 根据线索和关系投出凶手 | 组织投票，说明平票/裁定规则 | 结果由规则定，不由 DM 定（S1/S5） |
| 7. 复盘揭晓 | 听真相、提问、回顾亮点 | 铺垫→讲手法/时间线/动机/人物关系→互动→结束 | 真相在复盘才公开；复盘 10–15 分钟为宜（S6） |

## 四、DM 的核心职责与禁忌

**该做**（S2/S5/S6/S7）：

- 控节奏、发线索、推进阶段、组织投票、公布答案；卡住时推动，过热/过冷时调节气氛。
- 开场简述规则，游戏中提醒用角色姓名、第一人称、不贴脸。
- 复盘前先给「故事属于你们的时间结束了」这类信号；按投对/投错切换切入点（投对先讲人物关系与动机，投错先讲手法与时间线）；用提问把玩家拉回来；给结束语。

**不该做**（S2/S5/S6）：

- 不参与玩家对话、不主动嬉笑打闹、不替角色发言、不评判玩家或剧本。
- 不剧透；玩家偏题太多才在不剧透前提下引导，**不打破节奏、指手画脚**。
- 复盘不是照读手册，也不是开会式项目复盘；不调侃投错的玩家。

## 五、IMMS 现状对照（差距）

已有：L1 剧本事实 / L2 分配 / L3 涌现 / L4 表演，`InfoGuard` 与 `claimed_facts` 白名单，确定性投票与事件溯源，`gm_narrator` 每轮带案情事实的场景叙述，拉回并进叙述，`gm_direction` 导演层（GM 知真相、席位得私有目标），`replay` 逐轮实录。

对照真实剧本杀，仍缺这些**结构性环节**：

1. **开场/读本/自我介绍**没有独立阶段：runtime 直接进入按轮发言，没有 DM 讲背景和规则说明的环节。
2. **搜证不是玩家行为**：线索按 stage 由 GM 决定释放，缺行动点、地点/人物选择、公开/隐藏决定。
3. **私聊没有独立通道**：只有发言的 `target` 指向，没有两人私下交换信息的机制。
4. **分幕推进弱**：有 clue stage，但没有「未经允许不许翻页」的读本节奏。
5. **复盘不是 DM 讲述**：`replay` 是给开发者/审计看的静态报告，没有铺垫、投对/投错分支、互动提问、时长控制、结束语。
6. **玩家行为规范未系统化**：第一人称、不贴脸、不自曝、用角色姓名互称，只在个别 agent 提示里有，没进统一 prompt 约束。
7. **个人任务判定缺失**：`goals` 进了席位私有 prompt，但「隐藏秘密是否成功」没有判定与结算。

## 六、后续 GM 整体工作安排（已确认）

原则：**现实 DM 的表演/场地/NPC 不照搬**；IMMS 是文本多 agent 系统，GM 只负责阶段主持、信息分发、气氛与复盘语言。真值、数值、票数、可见性仍由确定性引擎决定，LLM 只写语言。

| 优先级 | 工作项 | 主要产出 | 验收标准 | 批次 |
|---|---|---|---|---|
| P0 | GM 责任边界与玩家规则对齐 | `gm_narration_lexicon` 加 DM 职责/禁忌；席位 prompt 加第一人称、不贴脸、不自曝、用角色姓名 | prompt 中出现规则条目；单测断言无内部 ID、无剧透 | 第一轮 |
| P1 | 阶段化流程：`intro → read/self-intro → investigate → discuss(按轮) → vote → reveal` | runtime phase 状态机 + 每阶段一次 GM 主持叙述 | 完整一局按阶段推进；每阶段一条 GM 叙述；旧 API 兼容 | 第一轮 |
| P2 | 搜证与私聊通道 | 线索卡 holder/visibility、行动点、公开/隐藏决定、私聊事件 | 线索可见性由 InfoGuard 裁剪；私聊只对双方可见；GM 不决定线索内容 | 第一轮 |
| P3 | DM 式复盘（**改造现有 replay**） | 在 `replay` 的逐轮实录后增加「主持复盘」段：铺垫→手法/时间线→动机/关系→互动提问→结束语；按投对/投错分支；审计明细仍在后文 | 真相只在复盘公开；长度受控；两种分支各出一份样本 | 第一轮 |
| P4 | 个人任务与真凶策略结算 | 目标完成判定、隐藏秘密成败、真凶搅浑水/栽赃行为记录 | 结算写事件；不扩大 `claimed_facts` 白名单 | 第二轮 |
| P5 | 真 agent 全链路验证 | 真 GM + 3–4 席位按新阶段跑完整局，规则 checklist 逐项核对 | 不用桩当文风证据；复盘实录按阶段可读 | 第一轮末尾 |

**第一轮范围：P0 + P1 + P2 + P3，最后用 P5 真跑验收。** 判断依据：当前最大缺口不是文风，而是**没有开场、没有搜证、没有真正的复盘**——这三处不补，GM 讲得再好也只是在按轮描述发言。P4（任务结算）放第二轮。

### 已确认的决策（2026-11-27）

1. **阶段化改造 runtime**：按真实剧本杀阶段推进，不是在按轮发言上继续叠加叙述。
2. **私聊与玩家主动搜证进第一轮**：与阶段化一起实现，一次到位。
3. **复盘改造现有 `replay`**：不新增独立产物；先放逐轮实录与 DM 式复盘讲述，后接审计明细。
