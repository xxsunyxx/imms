# 项目长期约定（IMMS）

- 选角/让用户在角色间选择时，只给公开人设与角色姓名，**绝不标注谁是真凶**（2026-11-26 用户明确指出）。
- 席位 agent 与 GM agent 的对外名字用剧本里的角色姓名（郑可欣 / 孟晓萌 / 韩子昂 / 沈巍 / 主持人）；`ai:<id>`、`actor-xxx` 只作内部键，不进 prompt、报告或复盘正文。
- GM 叙事按轮连续，掌握到当前轮为止的公开全景 + 自己的主持记忆；「跑偏拉回」只在人类玩家误导且多名 AI 跟随才触发，否则每轮只输出场景叙述。
- GM 读全本后知道真凶，真相只进 GM prompt 的「导演视角」段；真凶目标（隐藏、搅浑水、栽赃）与角色间私怨只进各自席位的私有 prompt。公开叙述不得泄露真相、票数、数值、未公开线索或自造台词。
- GM 每轮只输出一条场景叙述；拉回是叙述内部的自然转场，不是第二个 GM 事件或第二次 agent 调用。触发条件仍是人类玩家误导且至少两名席位跟随。
- 场景叙述要有信息量：必须带进客观案情事实或已揭示线索的具体内容；只写灯光气氛的空叙述会被校验回退。未揭示真相只在 GM 导演段，线索公开后其证实的私有事实才可讲。
- `revealed_clues` 落库值是 `c_report 急救初步判断记录|logLR:x=1` 这类展示串，不是裸 id；任何比较都要先经 `gm_direction.revealed_ids()` 归一化，否则会误判「线索未公开」并错误屏蔽已揭示事实。
