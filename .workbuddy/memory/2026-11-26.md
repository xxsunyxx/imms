## 10 轮 Prompt 波动实测（同日）

- 捕获逐轮 Prompt 的方法：monkeypatch `llm.build_prompt` 记录，再把 `llm.build_provider` 换成 `generate()` 抛 LLMError 的假 provider——这样强制走 Prompt 渲染，台词仍回退模板，无需真 LLM。模板 provider 本身不调用 `build_prompt`，直接 patch 会捕获 0 条。
